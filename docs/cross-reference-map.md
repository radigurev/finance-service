# Cross-Reference Map

Every SDD must map to its tests, implementation files, and (if applicable) frontend features. Update this file in the same PR as the spec.

Statuses (see `docs/README.md` → "Status lifecycle" for the authoritative definitions):
- **Planned** — named in the plan/inventory; no spec file authored yet
- **Drafted** — spec authored; may still change or be dropped; not yet committed
- **Active** — accepted & committed ("will be built to the end; should be implemented"); may be partially or not-yet built
- **Implemented** — code shipped + tests pass + in force (may carry explicit `Deferred:` notes for later-phase sub-items)
- **Deprecated** — retired or superseded; no longer in force

## Test infrastructure & Batch 15 (integration + frontend test harnesses)

- **Backend integration harness:** `src/Tests/Finance.IntegrationTesting` — Testcontainers (SQL Server + Redis + RabbitMQ), generic `FinanceApiFactory<TProgram>` (WebApplicationFactory), `FakeUserPermissionService` + `TestPermissionState` (RBAC), `TestTokens` (HS256 JWT), `DatabaseResetter` (Respawn). Integration tests are `[Category("Integration")]`, excluded from the default `TestCategory!=Integration` run; containers start only when an Integration test is selected. Requires Docker.
- **Real integration suites (Batch 15):** `Finance.Accounts.API.Tests/Integration` (15 — `SDD-ACCT-001`), `Finance.Journal.API.Tests/Integration` — `JournalEndpointIntegrationTests` (11 — `SDD-FIN-002`), `PostingEndpointIntegrationTests` (9 — `SDD-FIN-006`), `GeneralLedgerEndpointIntegrationTests` (6 — `SDD-FIN-003`). These replaced the former `Assert.Ignore`/`[Ignore]` placeholders and are green against live infra.
- **Frontend test harness:** `frontend` — Vitest + Testing Library + jsdom (`npm test`); `src/test/renderWithProviders.tsx`. 79 tests: 8 page components, 5 zod schemas, `getApiErrorMessage`, paging, EN/BG i18n parity.
- **Bugs found by the integration suite (fixed):** `CHG-FIX-001` (SequenceGenerator nested transaction → posting/reversal 500, `SDD-INFRA-003`/`SDD-FIN-002`), `CHG-FIX-002` (reversal audit `StateChange`→`Create`, `SDD-AUDIT-001`/`SDD-FIN-002`), `CHG-FIX-003` (`finance-journal` cache prefix, `SDD-INFRA-004`/`SDD-FIN-006`).
- **Frontend status correction:** the per-spec "Frontend" cells below were authored before the journal/periods/GL/posting-rules SPA pages shipped. Pages now present under `frontend/src/components/pages/`: `JournalEntriesListPage`, `FiscalPeriodsListPage`, `TrialBalancePage`, `AccountLedgerPage`, `PostingRulesListPage` (+ Accounts/Currencies/ExchangeRates). The "Planned/Deferred" notes in `SDD-FIN-002/-003/-004/-006` Frontend cells are superseded by these shipped pages (no automated UI tests beyond the Vitest component suite).
